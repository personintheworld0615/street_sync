# StreetSync — Modern v2 UI

Design direction based on `streetsync-home-modern-v2.png`.

## System

| Token | Value | Use |
| --- | --- | --- |
| Ink | `#111827` | Titles, primary text |
| Muted | `#6B7280` | Secondary text |
| Page | `#F7F8FA` | Backgrounds |
| Accent | `#0D9488` | Teal, sparingly |
| CTA | Soft black | Primary actions |
| High | Soft rose capsule | Severity |
| Medium | Soft amber capsule | Severity |
| Live | Soft green pulse | Status |

### Patterns
- Street photo / atmosphere on key headers (not flat Material blue)
- Frosted glass stats / overlays
- Borderless list rows with hairline separators
- Floating liquid-glass bottom tab bar (Home · Map · Community · Profile)
- Split Voice / Photo report control
- Soft sliding pill on selected filters — not chubby chips
- No heavy card chrome, multi-layer shadows, or Material blue (`#2196F3`)
